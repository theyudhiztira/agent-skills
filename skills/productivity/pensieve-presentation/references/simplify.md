# Simplify for the audience

Senior audiences read headlines and glance at the body. Simplifying means less on the slide, not less in the deck: detail moves to the speaker notes or an appendix.

## Patterns, with what they became in the reference deck

| Source shape | Do this | Example |
|---|---|---|
| A table of 15 rows across three slides | Group rows into 5 to 7 categories, one table, short cells | 15 data categories became 7 groups (maritime, air, land and border, intelligence, geospatial, operations, communications) |
| A seven-step flow | Merge to five steps, one line each | Each use case flow went from 7 steps to 5 |
| A checklist table with tick marks | A coverage view: one bar for overall progress, items grouped by area with a status marker | 22 agencies in a tick grid became "7 of 22 visited" with five groups |
| A paragraph of context with statistics | One sentence on the slide or none; figures and sources in the notes | Security incident figures moved to notes with source and month |
| A long objective paragraph | One lead sentence under the headline | "One picture of the waters, built from data agencies already hold, so suspicious activity is spotted earlier" |
| A list of stakeholders as bullets | One comma-separated line | |
| Architecture as a dense table | A layer stack with the focus layer highlighted | Six layers, layer 4 outlined |

## Rules

- **Keep only real numbers.** If the source has none for a point, write the point without a number or use `[__]`.
- **Counts must add up.** If a slide says 7 of 22, the groups must contain 22 items with 7 marked done. Check it.
- **Group with care.** When you invent a grouping the source did not have, say so in your reply so the person can move items.
- **Flag contradictions** (a status that differs between two source slides) instead of picking one silently. State which you chose and why.
- **Drop off-topic slides** (for example a comms topology slide in a deck about data fusion) and say what you dropped. Offer an appendix.
- **Keep images that prove something**: site visit photos, screenshots of the real product. Drop images that only decorate. Background textures from the source are not content.
